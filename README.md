## Multi-script

Petit script python qui permet de trier le dossier actuel, ainsi qu'une to-do list personnel.

Il suffit de lancer le script organisateur.py, celui-ci demandera l'input de l'utilisateur pour ce qu'il veut faire.

A noter, l'ajout des dossiers nécéssaires sont à réaliser au préalable.
